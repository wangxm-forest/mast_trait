\subsubsection{Data scraping}
For our analyses, we obtained the full species list from the two volumes of \textit{Silvics of North America} \citep{burns1990silvics,burns1990silvics2} (hereafter referred as \textit{Silvics}). We extracted masting data primarily from \textit{Silvics}. Pollination mode and seed dispersal data were also obtained mainly from \textit{Silvics}. We obtained seed weight data from the Seed Information Database by the Society for Ecological Restoration \citep{ser2023sid}, gathered seed dormancy data from \textit{Seeds} by Baskin and Baskin (2014) and accessed the leaf longevity and oil content data through the TRY database \citep{kattge2020try}. We compiled fruit size and drought tolerance data from multiple sources, including: \textit{Silvics}, the USDA Fire Effects Information System \citep{usfsfeis}, the USA National Phenology Network \citep{usanpn}, and The Gymnosperm Database \citep{gymnosperm}.

We defined masting based on qualitative descriptions of seed production patterns. Although recent studies emphasize quantitative definitions of masting, many forestry manuals view masting as a species-level categorical trait, including \textit{Silvics}. Thus, we classified species according to key phrases describing their seed production patterns. Species described as producing "a good crop almost every year" were classified as weak masting species, whereas species described as producing "a good crop every several years" or having "irregular seed production" were classified as strong masting species.

For some statistical analyses we grouped or otherwise adjusted the data on traits related to masting hypotheses. For numerical traits with a range (seed weight and fruit size), we recorded the full range from the source and took the mean value for further analyses. We took the log form of seed weight and fruit size to reduce the variability of data.
For categorical traits (pollination mode, reproductive type, and dispersal mode), we grouped them into broader categories; for example, we classified pollination mode into wind, animal (birds, bats, or insects), or both. The complete raw and processed datasets are available through KNB.

\subsection{Statistical Analysis}
\subsubsection{Masting pattern and single trait}

To analyze the relationship between masting pattern and individual traits, we used logistic regression, treating masting as a binary response variable. Given our species-level analyses, we used a phylogenetic logistic regression approach (\texttt{phyloglm} function in the \texttt{phylolm} package; v. 2.6.2). To construct the phylogenetic tree displaying the updated phylogenetic structure of our species, we verified all species names using the  \texttt{WorldFlora} package (v. 1.14-5) and updated all species names according to WCVP Backbone data (2025). We then constructed an ultrametric phylogenetic tree in R using the \texttt{phytools} (v. 2.4-4) and \texttt{ape} (v. 5.7-1) packages. To test the phylogenetic correction for each trait, we calculated the half-life using the equation $(\log(2)/\alpha)$ and compared it with the tree height (standardized to 1). This metric represents the time required for the influence of ancestral states to decrease by half. For more interpretation, see \cite{cooper2016cautionary}

\subsubsection{Phylogenetic signal for individual traits}
To check for the phylogenetic signal for all traits including masting, we used different metrics depending on the type of data. For traits that were binary, we calculated Fritz and Purvis' D-statistics using the function \texttt{phylo.d} in the \texttt{caper}  (v. 1.0.4) package. For categorical traits, we estimated the Pagel's $\lambda$ using the function \texttt{fitDiscrete} in the \texttt{geiger} (v. 2.0.11) package. For continuous traits, we calculated Pagel's $\lambda$ using the function \texttt{phylosig} in the \texttt{phytools} (v. 2.4-4) package.
